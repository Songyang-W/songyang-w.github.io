Brain-heart connectivity with multimodal deep learning

The brain and the heart constantly influence each other. Using data from a cohort of more than 1,000 animals, I combined EEG, ECG, other time series and tabular data to predict outcomes, and used interpretable models to see which signals drove each prediction.

  • CNN-LSTM
  • Random forest
  • XGBoost
  • LightGBM
  • SHAP
  • EEG and ECG

The problem

What made it hard

Each animal comes with several kinds of data recorded at different rates and scales. The model has to fuse them into one prediction.

The results also have to be explainable, so the scientists using them can see why the model made each call.

My work

What I built

  • Hybrid CNN-LSTM

    Convolutional layers pick up local patterns in the signals and an LSTM follows how they change over time (+3% AUC).

  • Strong classical baselines

    Tuned random forest, XGBoost and LightGBM models on the same multimodal features.

  • Interpretability

    Used SHAP to show which features drove each prediction.

  • Impact

    The results contributed to a funded NIH R01 grant.
